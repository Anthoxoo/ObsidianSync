**Schéma a connaitre :**

Source --> émetteur --> canal (peut intervenir du bruit ou des interférences / filtres qui peuvent nuire à la compréhension du message) --> récepteur --> destinataire avec un feedback qui part 
du destinataire à la source pour confirmer si le message a bien été compris ou non.

Source : élément qui souhaite faire passer le message
émetteur : élement qui fait passer le message
canal : moyen de faire parvenir ce message
récepteur élement recevant le message
destinataire : élement à qui le message été destiné

Communication : 
- interne --> communication interne a l'organisation, un employé à un responsable, un patron a un actionnaire etc, tant que les deux parties appartiennent d'une manière ou d'une autre à l'organisation c'est interne. Peut utiliser différents canaux : mails, messages teams / slack, réunion...
- externe --> communication externe à l'organisation, un community manager aux usagers du produit, cela a pour but de promouvoir l'image de l'organisation. Les canaux utilisés peuvent etre diverses a savoir : Réseaux sociaux, affiches, vidéos...

Modes de compréhension humains : 
- auditif --> retiens mieux en écoutant par le moyen d'un support : audio, parole etc
- kinesthésique --> retiens mieux en pratiquant ou en manipulant.
- visuel  --> retiens mieux à la vue de qq chose ex : texte, vidéo, image etc...
